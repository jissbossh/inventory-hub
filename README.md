# InventoryHub — Full-Stack Inventory Management

Aplicación full-stack en C#/.NET 8: Blazor WebAssembly (front-end) + ASP.NET Core Minimal APIs (back-end) + EF Core (SQLite en desarrollo).

## Cómo ejecutarlo
1. `dotnet restore`
2. `dotnet run --project src/InventoryHub.Api`
3. `dotnet run --project src/InventoryHub.Client`
